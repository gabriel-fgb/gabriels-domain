# gabriels-domain

A simple Flappy Bird-style browser game built with plain HTML, CSS, and JavaScript.

## Run locally

From this folder, start a static file server and open the shown URL:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- **Space** to flap
- **Click / Tap** to flap
- Avoid pipes and keep the bird airborne
